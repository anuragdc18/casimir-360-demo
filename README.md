# Casimir — 360° spin demo

A demonstration menswear storefront where every product tile is a real 360° spin-photography set.

- `index.html` — the whole site (no build step; open it directly or serve statically)
- `spins/` — one sprite sheet per product (24–48 frames each) plus a small poster frame
- `img/hero.jpg` — hero photograph

The spin frames are sample material from Sirv's public demo library and the hero is an Unsplash photo; both are placeholders to be replaced with the client's own product shoots (24–36 frames per item on a turntable, 4:5 crop).
